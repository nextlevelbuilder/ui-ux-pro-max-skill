# Drift rules

Every rule id `scripts/audit.py` can emit, with its detection logic, default severity and known false positives. Print the table with `python3 scripts/audit.py rules`. Contract loading, normalisation and the severity ladder are described after the rules.

## Contract-mode rules (require `--contract tokens.json`)

| Rule | Detection | Default severity | Kind | False-positive notes |
|---|---|---|---|---|
| `color.off-palette` | Every extracted opaque colour (Dart `Color(0xAARRGGBB)`, `Color.fromARGB/RGBO`, Material `Colors.<name>`; C# `new Color(r,g,b[,a])`, `Color32`, `TryParseHtmlString("#…")`; CSS/USS `#hex`, `rgb[a]()`, `hsl[a]()`; Tailwind `bg-[#…]` etc.; Swift `Color(red:green:blue:)`; Compose `Color(0x…)`) is normalised to `#RRGGBB` and looked up in the allowed set (all `$type: color` leaves, references resolved). Not found and luma-weighted distance to the nearest allowed colour **> 12** → finding. When the distance is > 30 the `fix` no longer recommends the far token but asks for the semantic role (primary/accent/surface/…) that matches the element's purpose; `nearest` stays in the JSON. | ladder (high when ≥ 3 occurrences of the same value or on a primary screen, else medium) | rule | Pure `#000000`/`#FFFFFF` with alpha < 1 (scrims, overlays) are never findings. Colours inside `box-shadow` / `BoxShadow` belong to the shadow signature and are masked. Material `Colors.blue[700]` shades other than 500 are inventory only (`named_colors`). |
| `color.near-duplicate` | Same extraction; distance to nearest allowed colour **≤ 12** (`--near-threshold`). Calibration: 12 ≈ 20 units on G alone, 22 on R, 35 on B. | low (always) | rule | A deliberately lighter tint one step off the palette will be reported; add it to the palette or to `intentional_exceptions`. |
| `radius.off-scale` | `BorderRadius.circular(n)` / `Radius.circular(n)`, CSS `border-*-radius: …` (every px/rem value in shorthand), Tailwind `rounded-[npx]`, JS `borderRadius: n`, `--*radius*:` custom properties, Swift `.cornerRadius(n)`, Compose `RoundedCornerShape(n.dp)`; compared with every radius value in tokens.json (all layers, see Contract loading). Values ≥ 999 normalise to `pill` and match any contract radius ≥ 999; `0` is always allowed. | ladder | rule | Integers must hit a step exactly; non-integers get ±1 (rem conversion noise). `--tolerance N` overrides both. Percent radii are not read. |
| `font-size.off-scale` | Dart `fontSize: n`, CSS `font-size: n(px\|rem\|em\|pt)`, Tailwind `text-[n]`, JS `fontSize:`, `--*font-size*:`/`--text-*:` vars, Swift `.font(.system(size:))`, Compose `fontSize = n.sp`; compared with every font-size value in tokens.json (all layers). | ladder | rule | Keyword sizes (`small`, `larger`) ignored. `pt` × 4/3, `rem/em` × 16. |
| `font-family.unlisted` | Families from five sources, each with file:line evidence: (1) Dart `fontFamily: '…'` and `GoogleFonts.<camel>()` (→ Title Case); (2) CSS/USS `font-family:` first item, including `<style>` blocks and inline `style="…"` attributes in `.html .vue .svelte`; (3) `--*font*:` custom properties; (4) **Tailwind theme** `fontFamily: { key: ['Family', …] }` or `key: 'Family, fallback'` — first (primary) family of each entry, in `tailwind.config.{js,ts,cjs,mjs}` and in an inline `tailwind.config = {…}` `<script>` of an HTML page; (5) **Google Fonts** loader URLs `fonts.googleapis.com/css2?family=A:wght@…&family=B` and `css?family=A|B` in `<link href>`, CSS `@import url(…)` and JS strings — `+`/`%20` decode to spaces, `:wght@…` / `:ital,wght@…` / `:400,700` suffixes are stripped, `&amp;` separators are handled. All sources also feed `inventory.font_families`. | ladder (one wrong family loaded via Google Fonts and named in the Tailwind theme counts 2; a third mention makes it high) | rule | Generic families (`sans-serif`, `serif`, `monospace`, `system-ui`, `cursive`, …), `var(…)`, `inherit` and Vue `:style` / `v-bind:style` bindings are never findings. Not read: SVG presentation attributes (`<text font-family="Arial">`), `next/font` imports, `@font-face` `src:` URLs, and fonts loaded by other CDNs (Bunny, Adobe Fonts). Without a contract family list (no `primitive.fontFamily`, no `$extensions.vdp.fontFamilies`) the rule has nothing to compare and only the inventory is filled. |
| `spacing.off-scale` | Dart `EdgeInsets.all/symmetric/only/fromLTRB(...)` (every number), CSS `padding`/`margin`/`gap` (+ sides, every px/rem value), Tailwind `p-[…]`/`m-[…]`/`gap-[…]`, `--*space*|spacing|gap*:` vars; compared with every spacing value in tokens.json (all layers). | low; medium when ≥ 3 occurrences; never high | rule | Noisy by nature: `SizedBox(height: n)` spacers are inventory only; percentages, `auto` and `calc()` are not read. |

Duration `0` ignored. | medium; high when ≥ 3 occurrences (primary screen does not raise it) | rule | Delays are not distinguished from durations. Same scale rule as every other category (CC-13): integers must hit a listed step exactly, non-integers get ±1; only an explicit `--tolerance N` widens the band. `primitive.duration` may carry `reward`/`ambient` steps (CC-8) — they are simply more listed values. |
| `shadow.unlisted` *(extension id)* | Each literal `BoxShadow(...)` and `box-shadow:` layer (and `--*shadow*:` vars) becomes a platform-neutral signature `x= y= blur= spread= color= a=`; signatures not among the contract's shadow signatures (every `$type: shadow` value of every layer, one signature per comma-separated layer, so tinted component hard shadows like `0 4px 0 #972743` are allowed) → one finding per occurrence. | low | rule | Non-literal values are skipped and never counted as variants: `box-shadow: var(--shadow-card)`, `none`, `inherit`, `initial`, `unset`, `{token}` references, and Dart `BoxShadow` whose colour is an identifier (`AppColors.shadow`). | `shadow.variant-explosion` | Distinct signatures project-wide > number of distinct contract shadow signatures (all layers, `none` excluded) → **one** finding pointing at the first occurrence of the first unlisted signature; `message` lists `distinct=N allowed=M` and every signature with counts. | medium | rule | Identical shadows written in Dart and CSS collapse to one signature (tested). |

Works in inventory mode too. |
| `component.duplicate-implementation` | Definitions whose name matches the component family regex (`…Button…`, `…Popup|Dialog|Modal|Sheet|Toast|Snackbar|Card|Badge|Chip`) from `class X extends StatelessWidget|StatefulWidget|…`, `export function|const X`, `class X : MonoBehaviour|VisualElement`. Within one platform group, the same family in ≥ 2 files → one finding per non-canonical file. Canonical = first sorted file under `widgets/ components/ ui/ shared/ design_system/` (else the first sorted file). Body whitespace-normalised: identical → "copy-paste duplicate", else "divergent re-implementation". | medium | recommendation (heuristic) | Name-based: `IconButton` wrappers around a design-system button are reported; make them a variant of the canonical component or accept the finding. |
| `touch.target-too-small` | Dart `SizedBox(width/height …, child: IconButton|InkWell|GestureDetector|…Button)` and `minimumSize: Size(w, h)`; CSS rule with a button-like selector (`button`, `[role=button]`, `.*btn*`, `.*icon-btn*`, `.*fab*`, `.*chip*`, `.*tap*`) carrying **both** width and height (or min-*). | `text.contrast-risk` | Within one CSS/USS rule body, literal `color: #hex` and `background[-color]: #hex` → WCAG 2.x contrast ratio; < 4.5 → finding (ratio in the message). | medium, always (heuristic cap); never high or critical statically | recommendation (heuristic) | `var()` on either side is not evaluated (no finding, no claim). ## Inventory-mode rules (no `--contract`)

Only variant explosions plus the four rules that need no palette (`icon.mixed-libraries`, `component.duplicate-implementation`, `touch.target-too-small` with threshold 44, `text.contrast-risk`). All variant explosions are `medium`, `kind: recommendation`; `evidence` is the value with the fewest occurrences (the most likely stray), `message` lists every value with counts, `fix` is "define a scale in tokens.json (`vd.py init`) and re-run with `--contract`".

| Rule | Trigger (distinct values project-wide) |
|---|---|
| `radius.variant-explosion` | > 4 (excluding 0 and pill) |
| `font-family.variant-explosion` | > 3 (generic families excluded) |
| `font-size.variant-explosion` | > 8 |
| `duration.variant-explosion` | > 6 |
| `color.variant-explosion` | > 24 opaque distinct |
| `shadow.variant-explosion` | > 6 |

## Contract loading

**Every literal value of every layer is allowed.** The loader walks every top-level layer that does not start with `$` — `primitive`, `semantic`, `component`, an optional `dark` theme layer and any other theme layer. A leaf is `{"$value", "$type"}`; `{a.b.c}` references resolve recursively (depth ≤ 10; an unresolved reference is a note and the leaf is ignored). Each resolved literal joins the allowed set for its `$type`. Generated contracts emit component literals that are not primitives (for example `component.button.primary.pressDuration = 90ms`, or tinted hard-edge shadows `0 4px 0 #972743, 0 8px 12px rgba(46, 42, 50, 0.14)`); code that copies them verbatim scans clean.

| `$type` | Allowed set |
|---|---|
| `color` | every hex value → `{hex: token path}` |
| `dimension` | assigned to a scale by any segment of its path: `radius`/`corner` → radius; `fontSize`/`font-size`/`textSize` → font size; `spacing`/`padding`/`gap`/`margin`/`inset`/`gutter`/`space` → spacing. `semantic.radius.control`, `component.button.primary.radius`, `component.*.paddingX`, `semantic.spacing.stack` all join. Heights, widths, outline widths, icon and touch sizes join no scanned scale. Values normalised to px. |
| `duration` | every value in ms (`ms`/`s`/unitless) |
| `shadow` | every literal string value, one signature per comma-separated layer; `none`, `var()` and references-to-nothing are skipped |
| `fontFamily` | every value (first family of a stack) ∪ `$extensions.vdp.fontFamilies` ∪ profile `typography.display/body` |

`minTouchTarget`, `iconLibrary` and `platformUnit` come from `$extensions.vdp` (`minTouchTarget` falls back to `primitive.touchTarget.min`, then 44).

**Naming (`nearest`, `fix`).** When several paths resolve to the same value, the finding names the first in the order semantic → component → primitive → other layers (`dark`, …). The role name is the most useful replacement for screen code, a component path is more specific than a raw primitive, and a light-theme screen should not be pointed at a dark-theme token. Example: a 95 ms press animation gets `nearest: component.button.primary.pressDuration 90 (scale …)`; a 15 px label gets `primitive.fontSize.sm 14` when no semantic or component token carries 14.

Missing primitive groups are notes, not errors (that is `vd.py validate`'s job). A file that is not a token document (no `primitive`/`semantic`/`component` layer) → exit 1; a missing file → exit 2.

## Non-literal values

A value is only compared when it is a literal. `var(--x)`, `env()`, `theme()`, `calc(var(--r) + 2px)`, `{primitive.radius.md}`, Sass `$x` / Less `@x`, the keywords `none inherit initial unset revert auto transparent currentColor`, and Dart/C# identifiers (`AppRadius.md`, `Theme.of(context)…`, `AppColors.primary`) are never literals: they produce no finding and no inventory entry. This is the mechanism that keeps a token-driven sheet at zero findings.

## Normalisation

Hex → `#RRGGBB` upper, alpha kept separately (inventory key `#RRGGBB@a.aa`); Unity float channels → `round(x·255)`; `rem`/`em` × 16, `pt` × 4/3, `dp`/`sp`/logical = px; durations → integer ms; radii ≥ 999 → `pill`; families trimmed, unquoted, compared case-insensitively; shadows → signature; evidence = matched text, whitespace collapsed, ≤ 120 chars.

## Related check outside this skill

`node ../design-system/scripts/validate-tokens.cjs --dir src/` (the `design-system` skill) is a web-only complement, not a replacement: it scans `.css .scss .ts .tsx .js .jsx .vue .svelte` (not `.html`, and it skips `globals.css`), flags every hex/px literal without a contract, and does not read Dart, USS, UXML or C#.

## Files and platforms

Platform markers (depth ≤ 2): `pubspec.yaml` → flutter; `ProjectSettings/ProjectVersion.txt`, `*.csproj`, `Assets/` → unity; `package.json` → web; `Package.swift`, `build.gradle[.kts]`, `*.xcodeproj` → native. One marker → that platform, several → `mixed`, none → `unknown` (not an error: generic patterns run on every supported extension with a warning). `--platform <x>` forces the label **and** restricts scanning to that platform's extensions (warning when 0 files match).

**Flutter scaffold:** when `pubspec.yaml` sits at the root, the stock `flutter create` glue folders `android/ ios/ macos/ linux/ windows/` are skipped for detection and scanning (they hold `MainActivity.kt`, `AppDelegate.swift`, Gradle and Xcode files, not UI), and `web/` is skipped too when it is the Flutter web shell (`index.html`/`manifest.json` without a `package.json`). A stock app therefore reports `platform: flutter`, not `mixed`, and the experimental Swift/Kotlin extractors stay off; `--platform native` scans those folders explicitly. A `web/` folder with its own `package.json` is a real web project and is kept (that is why the test fixture is `mixed`).

Extensions: `.dart` · `.cs .uss .uxml` · `.css .scss .tsx .jsx .ts .js .cjs .mjs .vue .svelte .html` · `.swift .kt` (experimental). In `.html .vue .svelte` files, `<style>` blocks and inline `style="…"` attributes run through the full CSS declaration extractors (radius, size, spacing, duration, family, shadow, contrast — then blanked so colours are not counted twice), and the rest of the page, including inline `<script>` such as `tailwind.config = {…}`, runs through the markup/JS extractors. A selector that follows an at-statement (`@import url(…); h1 { … }`) is cut at the last `;`. Google Fonts URLs are read from every web and CSS-like file. Skipped: directories `build .dart_tool node_modules Library Temp Logs obj bin .git dist .next coverage __pycache__ .idea .vs Pods DerivedData .gradle` and any dot-directory; files `*.g.dart *.freezed.dart *.gr.dart *.min.css *.min.js *.map *.lock`, > 1 MiB, NUL in the first 4 KiB, any line > 5000 chars; `--exclude <glob>` adds patterns. Skipped scannable files are counted in `skipped_files`. Comments are stripped string-aware (a `//` inside `'https://…'` is not a comment); string literals are kept because design values live in them.
