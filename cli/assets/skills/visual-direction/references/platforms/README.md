# Platform adapters

How a `design-system/<slug>/tokens.json` (contract §4.2, CC-7 leaf names) lands in code on each stack. Every file uses the same 8-section skeleton: 1 where tokens live · 2 token group → code mapping · 3 component reuse patterns · 4 migration order when fixing drift · 5 what not to touch · 6 screenshot capture for QA · 7 performance notes · 8 known limitations.

| File | Stack ids (`product.stack`) | `platformUnit` |
|---|---|---|
| `flutter-flame.md` | `flutter`, `flutter-flame` | `logical` (bare numbers) |
| `unity.md` | `unity-ugui`, `unity-ui-toolkit` | `px` against the 1080×1920 reference resolution |
| `web.md` | `react`, `nextjs`, `vue`, `svelte`, `html-tailwind` | `px`; CSS generated by `../design-system/scripts/generate-tokens.cjs` |
| `mobile-native.md` | `swiftui`, `jetpack-compose` | `pt` / `dp` |

Shared conventions: components read `component.*` leaves only (one shared implementation per group — `button`, `card`, `popup`, `hud.chip`, `tile`, `progress`); appearing motion uses `primitive.easing.enter`, leaving motion `primitive.easing.exit`; toast lifetime is not a token and is computed as `primitive.duration.reveal` × 6 in the shared toast component; screenshot file names follow `<screen>_<device>.png` with devices `phone_small`, `phone_tall`, `android`, `tablet` (plus `desktop` on web).

## Verification

Token paths were checked against the canonical example `tokens.example.japanese-cute-puzzle.json` (Wave 1, Agent 5): every `primitive.*` / `semantic.*` / `component.*` path written in these four files (brace sets such as `primitive.radius.{none,xs,sm}` expanded, trailing `.*` treated as a group) must exist as a leaf or a group in that file.

| File | Distinct token paths | Missing |
|---|---|---|
| `flutter-flame.md` | 87 | 0 |
| `unity.md` | 83 | 0 |
| `web.md` | 47 | 0 |
| `mobile-native.md` | 51 | 0 |

Result: PASS (2026-10-15). Also checked: every code skeleton is ≤25 lines; the only script invocations are `../design-system/scripts/generate-tokens.cjs` and `../design-system/scripts/validate-tokens.cjs` (both exist); the web adapter keeps the exact invocation `node ../design-system/scripts/generate-tokens.cjs --config design-system/<slug>/tokens.json -o <out>`.

Known gap: the example file carries `primitive.duration.{instant,fast,base,slow,reveal}` only; the `reward`/`ambient` keys added by CC-8 are mentioned in prose and must be generated conditionally until the emitting `vd.py init` writes them.
